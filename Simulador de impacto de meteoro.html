O que eu coloquei no protótipo

  • UI para inserir: diâmetro (m), densidade (kg/m³), velocidade (km/s), ângulo (°), latitude/longitude e se o impacto é em terra ou oceano.

  • Cálculos básicos no cliente: volume → massa, energia cinética (J e equivalente em megatons TNT), estimativa aproximada de diâmetro de cratera e raio de explosão (valores heurísticos — protótipo).

Fontes e modelos que recomendo integrar (usei para referência)

  • Earth Impact Effects Program (Collins, Melosh & Marcus) — referência principal para modelos de efeitos regionais de impactos (blast, térmico, escombros, cratera). Recomendo incorporar/portar suas equações ou chamar o código/algoritmos deles. Impact Earth+1

  • Holsapple — escalas e leis de crateramento (escala para diâmetros de crateras e dependência de propriedades do alvo). Para estimativas de cratera e regimes de força vs gravidade use esses trabalhos. LPI+1

  • Impact: Earth! (Purdue) — outra calculadora web bem conhecida que ajuda a validar fórmulas e resultados. Purdue University+1

  • Dados populacionais — GPWv4 / SEDAC (Gridded Population of the World) para estimar mortes ao intersectar a área afetada com densidade populacional. Você pode baixar mosaicos de 1 km (ou agregados) e fazer o overlay para estimar vítimas. NASA Earthdata+2AidData+2

  • Globo 3D / visualização — CesiumJS, three.js, react-globe.gl / Mapbox / MapLibre para animações e exibição da superfície (cesium é ótimo para mapas globais precisos; react-globe.gl é rápido para protótipos). Cesium+2Mapbox+2

Como transformar o protótipo num site realista (passo a passo)

  1. Escolher arquitetura

    • Frontend: React (Vite/Create React App) + react-globe.gl ou CesiumJS para visual 3D.

    • Backend: Node.js (Express) ou Python (Flask/FastAPI) para processamento pesado e acesso a grandes rasters (população, batimetria).

    • Armazenamento: objetos (S3 ou equivalente) para rasters/processados e tiles raster georreferenciados.

  2. Modelos e algoritmos

    • Portar as equações do artigo Collins et al. (2005) — blast, térmico, escombros, crateramento e sismo.

    • Usar leis de escala Holsapple para cratera e regime (forte vs gravidade).

    • Para tsunamis (impacto oceânico): use simplificações ou bibliotecas de modelagem de onda; para alta fidelidade é necessário solver hidrodinâmico (ex.: GeoClaw) — tipicamente feito no backend.

  3. Dados geoespaciais

    • População: GPWv4 (rasters de 1 km) — agregue à resolução desejada no backend; para estimativas rápidas pode usar versões agregadas (15' ou 1°). NASA Earthdata+1

    • Batimetria / elevação: SRTM (terrestre) + ETOPO/GEBCO para oceano — necessário para estimar inundação/propagação de tsunamis.

    • Map tiles: Mapbox/Cesium/MapLibre para base de mapa.

  4. Estimativa de vítimas e impactos

    • Gere polígonos de áreas afetadas (p. ex. sobrepressão ≥ X psi, raio térmico, densidade de escombros) a partir dos cálculos.

    • Intersecte essas áreas com o raster de densidade populacional para estimar população exposta. (soma das células * densidade * probabilidade de sobrevivência)

    • Modele incerteza: forneça intervalos (mín-médio-máx) usando parâmetros variantes (densidade do meteoro, ângulo, fragmentação).

  5. Visualização / Animação

    • Animação da entrada: trajetória e iluminação (three.js / Cesium).

    • No impacto: círculos / polígonos de sobreposição que crescem (blast, thermal, ejecta) e heatmap de mortalidade estimada.

    • Camadas toggle: crater, onda de choque, mortos estimados, danos estruturais, tsunami height (se oceano).

  6. Performance & segurança

    • Fazer cálculos pesados (convoluções raster, modelagem de tsunami) no backend. Frontend pede resultados via API e exibe.

    • Evitar execução de modelos que possam ser mal utilizados para causar pânico; inclua avisos e fontes científicas.

Boa 🚀 — adicionei partículas de fogo e fragmentos. A ideia é usar THREE.Points para partículas incandescentes na descida e um efeito de “spray” no impacto. Assim, você terá:

  • Na queda: o meteoro é seguido por uma trilha de faíscas (pontos laranja/amarelos piscando).

  • No impacto: fragmentos se espalham radialmente e desaparecem após alguns segundos.

  • Explosão: o círculo pulsante continua mostrando o raio de explosão.

Como funcionaria (passo a passo da animação)

  1. Meteor spawn: esfera emissiva laranja/vermelha posicionada acima do planeta.

  2. Particle trail: atrás do meteoro, um THREE.Points com partículas que se renovam a cada frame (imitando faíscas que queimam na atmosfera).

  3. Impact: quando o meteoro atinge a superfície, a esfera some → gera:

    • Um anel de choque (círculo pulsante, já implementado).

    • Um spray de fragmentos: pequenas partículas lançadas em direções aleatórias que se dissipam (escala diminui e cor apaga).

  4. Cleanup: partículas desaparecem em alguns segundos para não sobrecarregar a cena.

Exemplo de código para integrar (dentro do playAnimation)

// trilha do meteoro (faíscas)
const particleCount = 200;
const particles = new THREE.BufferGeometry();
const positions = new Float32Array(particleCount * 3);
for (let i = 0; i < particleCount; i++) {
  positions[i*3] = meteor.position.x;
  positions[i*3+1] = meteor.position.y;
  positions[i*3+2] = meteor.position.z;
}
particles.setAttribute('position', new THREE.BufferAttribute(positions, 3));

const particleMaterial = new THREE.PointsMaterial({
  color: 0xffaa00,
  size: 0.1,
  transparent: true,
  opacity: 0.8
});
const trail = new THREE.Points(particles, particleMaterial);
scene.add(trail);

// atualizar partículas durante a descida
function updateTrail(){
  const positions = trail.geometry.attributes.position.array;
  for(let i=0; i<particleCount; i++){
    positions[i*3] += (Math.random()-0.5)*0.1;
    positions[i*3+1] += (Math.random()-0.5)*0.1;
    positions[i*3+2] += (Math.random()-0.5)*0.1;
  }
  trail.geometry.attributes.position.needsUpdate = true;
}

function init() {
  scene = new THREE.Scene();
  camera = new THREE.PerspectiveCamera(60, window.innerWidth/window.innerHeight, 0.1, 1000);
  camera.position.z = 5;

  renderer = new THREE.WebGLRenderer({antialias:true});
  renderer.setSize(window.innerWidth, window.innerHeight);
  document.body.appendChild(renderer.domElement);

  // Luz
  const light = new THREE.PointLight(0xffffff, 1);
  light.position.set(5,5,5);
  scene.add(light);

  // Terra
  const earthGeo = new THREE.SphereGeometry(1.5, 32, 32);
  const earthMat = new THREE.MeshPhongMaterial({ color: 0x2233ff, flatShading: true });
  earth = new THREE.Mesh(earthGeo, earthMat);
  scene.add(earth);

  animate();
}

function animate() {
  requestAnimationFrame(animate);
  earth.rotation.y += 0.002;
  renderer.render(scene, camera);
}

☄️ 4. Função para rodar a simulação

js
function playAnimation() {
  const size = parseFloat(document.getElementById('size').value) / 100;
  const speed = parseFloat(document.getElementById('speed').value) / 50;

  // Cria o meteoro
  const meteorGeo = new THREE.SphereGeometry(size, 16, 16);
  const meteorMat = new THREE.MeshBasicMaterial({ color: 0xff5500, emissive: 0xff2200 });
  meteor = new THREE.Mesh(meteorGeo, meteorMat);
  meteor.position.set(0, 3, 0);
  scene.add(meteor);

  // Loop da animação
  function fall() {
    if (meteor.position.y > 0) {
      meteor.position.y -= speed * 0.05;

      // Criar faíscas (trilha)
      const particleGeo = new THREE.SphereGeometry(0.02, 4, 4);
      const particleMat = new THREE.MeshBasicMaterial({ color: 0xffaa00 });
      const spark = new THREE.Mesh(particleGeo, particleMat);
      spark.position.copy(meteor.position);
      scene.add(spark);

      setTimeout(() => scene.remove(spark), 500); // desaparecer

      requestAnimationFrame(fall);
    } else {
      scene.remove(meteor);
      createExplosion();
    }
  }
  fall();
}

function createExplosion() {
  const geo = new THREE.RingGeometry(0.1, 0.2, 32);
  const mat = new THREE.MeshBasicMaterial({ color: 0xff0000, side: THREE.DoubleSide });
  explosion = new THREE.Mesh(geo, mat);
  scene.add(explosion);

  let scale = 0.1;
  function expand() {
    if (scale < 5) {
      scale += 0.1;
      explosion.scale.set(scale, scale, scale);
      requestAnimationFrame(expand);
    } else {
      scene.remove(explosion);
    }
  }
  expand();
}

let scene, camera, renderer, earth, meteor;

init();

function init() {
  scene = new THREE.Scene();
  camera = new THREE.PerspectiveCamera(60, window.innerWidth/window.innerHeight, 0.1, 1000);
  camera.position.z = 5;

  renderer = new THREE.WebGLRenderer({antialias:true});
  renderer.setSize(window.innerWidth, window.innerHeight);
  document.body.appendChild(renderer.domElement);

  const light = new THREE.PointLight(0xffffff, 1);
  light.position.set(5,5,5);
  scene.add(light);

  const earthGeo = new THREE.SphereGeometry(1.5, 32, 32);
  const earthMat = new THREE.MeshPhongMaterial({ color: 0x2233ff, flatShading: true });
  earth = new THREE.Mesh(earthGeo, earthMat);
  scene.add(earth);

  animate();
}

function animate() {
  requestAnimationFrame(animate);
  earth.rotation.y += 0.002;
  renderer.render(scene, camera);
}

function playAnimation() {
  const size = parseFloat(document.getElementById('size').value) / 100;
  const speed = parseFloat(document.getElementById('speed').value) / 50;

  meteor = new THREE.Mesh(
    new THREE.SphereGeometry(size, 16, 16),
    new THREE.MeshBasicMaterial({ color: 0xff5500, emissive: 0xff2200 })
  );
  meteor.position.set(0, 3, 0);
  scene.add(meteor);

  function fall() {
    if (meteor.position.y > 0) {
      meteor.position.y -= speed * 0.05;

      // Trilhas de faíscas
      const spark = new THREE.Mesh(
        new THREE.SphereGeometry(0.02, 4, 4),
        new THREE.MeshBasicMaterial({ color: 0xffaa00 })
      );
      spark.position.copy(meteor.position);
      scene.add(spark);
      setTimeout(() => scene.remove(spark), 500);

      requestAnimationFrame(fall);
    } else {
      scene.remove(meteor);
      createExplosion();
    }
  }
  fall();
}

function createExplosion() {
  const geo = new THREE.RingGeometry(0.1, 0.2, 32);
  const mat = new THREE.MeshBasicMaterial({ color: 0xff0000, side: THREE.DoubleSide });
  const explosion = new THREE.Mesh(geo, mat);
  scene.add(explosion);

  let scale = 0.1;
  function expand() {
    if (scale < 5) {
      scale += 0.1;
      explosion.scale.set(scale, scale, scale);
      requestAnimationFrame(expand);
    } else {
      scene.remove(explosion);
    }
  }
  expand();
}
